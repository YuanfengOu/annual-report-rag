# 15家公司年报问答知识库（方向A）

Python 3.12；本地Ollama，qwen3:8b（Q4_K_M）与qwen3-embedding:0.6b（Q8_0）。无需API key。

## 运行

在仓库根目录建立虚拟环境并安装requirements.txt。另行安装Ollama，执行：

```
ollama pull qwen3:8b
ollama pull qwen3-embedding:0.6b
python restore_corpus.py
python 第三步知识库/scripts/build_index.py
python -m streamlit run 第三步知识库/app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

先确保Ollama服务运行在127.0.0.1:11434。打开Streamlit终端给出的本地地址。向量索引由已附的复核语料重新生成，首次需要时间；请勿将参考答案和实验记录加入索引。代码以文件相对位置定位仓库，无需保留原电脑D盘路径。

## 材料与预处理

年报来源.json提供15家公司的交易所或巨潮资讯公告页面及原文件名。进入对应公告下载年度报告全文，按source_file命名放在年报原文目录。公告入口不保证是PDF直链，不能直接将网页HTML保存为PDF。无需在仓库发布原始PDF。

语料以 `第二步材料处理/复核修订版/chunks.jsonl.gz` 无损压缩保存，以适配网页上传限制。先在仓库根目录执行 `python restore_corpus.py`，脚本将恢复 `chunks.jsonl` 并验证 SHA-256；只需 Python 标准库，无需额外依赖。

本版本附复核后的9564块语料及60条核心财务指标，可复建索引与复现问答；并非从零自动完成全部人工核验的流水线。预处理采用约800字符、120字符重叠，保留公司/章节/页码，低质量页作版面修复，60条指标与PDF核对。完整原始预处理过程留存在作业本地材料中。

## 方法及边界

文字问答：向量与BM25两路召回，RRF融合；主题词精确匹配为后续新增补充通道。金融核心指标：公司/年份/指标结构化读取已核验行，Decimal计算和引用拼接。多年份只支持特定2025/2024同比与调整口径查询，不支持任意跨年比值。60条财务行之外不保证数值可靠。

首次后台三组30次测试严格通过BM25 3/10、向量5/10、混合6/10。后续网页实测6/10，问题修复和用户复测后固定10题最终均有合格演示。它们是开发集，不是独立泛化测试；未训练或微调模型。实验原始记录保留失败，不应仅选最终成功结果报告。

原记录中的本地来源路径用于追溯旧环境；运行代码使用相对目录。JSON中的候选分数和证据是实际导出，某些结构化查询不存在向量召回得分。PDF缺失时页面仍可问答并展示文字证据，但无本地PDF下载按钮。
